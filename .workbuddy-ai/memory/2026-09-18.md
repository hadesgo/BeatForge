## 多图合成：堆叠很乱、并排割裂（用户反馈）
用户反馈：「当同一个镜头用两张图片的时候，有一张图片在背后虚化。两张图片重叠在一起的时候，
画面看上去很乱。而且两张图片并排的时候，看起来很割裂」。

### 根因：单图的"留边 + 虚化副本"被用进了合成
`_adapt_image` 是为**一张填不满画面的图片**设计的：按 `image_foreground_scale`（默认 .92）
缩放居中，周围用**同一张图的虚化副本**（`gblur` + 压暗去饱和）补满。
四个多图效果（`split_screen`/`photo_stack`/`double_exposure`/`beat_montage`）**每张图都套了这一层**，
于是错两次：
1. **一帧里有两个互相竞争的虚化底**——每张图各自带一片；
2. **同一张图以两个尺度出现两遍**。

具体表现（渲染出来看过）：
- **堆叠**：底图 = 清晰的自己（92%）叠在自己的虚化副本上，再往上压卡片 → **三个尺度同框**，最乱；
- **并排**：一格走留边处理、另一格全出血 → 两边取景和曝光看着就不一样，读起来像两张恰好挨着的图，
  而不是一张图被切成两半。这就是"割裂"；
- **双重曝光**：两层虚化底一起 screen 混合 → 糊成一片。

### 修复
新增 `_fill_frame()`：`scale=...:force_original_aspect_ratio=increase` + `crop`，**全出血不留边**。
四个合成效果全部改用它；**单图效果仍保留留边处理**（那是它存在的理由——竖图放进横画布时裁掉太可惜）。
堆叠的底图另外压暗去饱和（`eq=brightness=-.085:saturation=.74`），让卡片读得出来。

### 确认过但不是问题的
调色（`_shot_match_filter` / `grade_filter` / `_section_color_filter` / vignette / grain）
是在**合成之后**统一套的（`_image_filter_graph` 返回的标签才进 finishing），
所以两格共享同一个 grade——"割裂"不是调色各调各的造成的。

### 测试（`tests/test_renderer.py` +8 条）
- `test_a_composite_never_letterboxes_a_panel`（4 个效果参数化）：合成图里**不得出现 `gblur`**，
  且必须有 `increase`；
- `test_every_panel_of_a_split_covers_its_slot`（3 个效果）：不得有 `decrease`，
  且恰好 2 个 `increase`；
- `test_a_single_image_still_gets_its_blurred_backdrop`：**单图仍要有 `gblur` 和 `decrease`**——
  这条是防止修复越界，把留边处理从它该在的地方也拿掉。

### 探针
`.probe/composite_probe.py`：用 16:9 和 3:4 两张源图渲染四个合成效果并出接触表——
两种形状才能逼出留边路径。注意要用 `_render_shot()` 而不是 `render()`（单镜头走 `render()`
会在 concat 步骤失败）。
