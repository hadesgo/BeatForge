### GGUF 下载源改为魔搭
- `_download_gguf` 原来硬编码 `hf_hub_download`，**完全绕过了 provider 机制**——所以
  `--source` 对它无效。现在它与快照走**同一套 provider 顺序**（`auto` = modelscope → HF 回退），
  只是选项由 `_gguf_options` 生成：`allow_patterns` + `local_dir`，仍只下一个量化文件。
- **`allow_patterns` 对 Hugging Face 必须是 list**：它按 pattern 迭代，传裸字符串会被逐字符匹配、
  一个文件都下不到（modelscope 两种都吃）。这条写进了 `_gguf_options` 的 docstring。
- 落盘目录 `cache_dir/director` 与 `llama_server.find_gguf` 的查找目录保持一致，
  新增测试直接断言 `find_gguf(...) == Path(director.local_path)`，避免"下载成功但运行时找不到"。
- 已用 `inspect.signature` 核对装机的 modelscope 1.39.1 与 huggingface_hub 1.29.0 都支持
  `allow_patterns` / `local_dir` / `model_id|repo_id`。
